# research-to-policy

A Claude Code harness for applied empirical, data-analytical, and policy research — adapts scc's planning/handoff/verification discipline to the realities of policy research and applied development economics.

**v3.1 shipped 2026-09-10 — the Córdoba v3 assessment acted on.** **Current focus: nothing open.** No plan directory exists under `plan/`; v3.1 was done directly rather than through a plan, so there is no archive entry for it — `docs/v3-assessment-cordoba.md` is the record.

**What v3.1 is, in one line: the framework stopped pushing and started only checking.** The measurement that drove it (285 evidence docs, 194 method+source docs, 6 months) sorted every r2p mechanism by whether it *checks* or *injects* and found the split total — **every enforced constraint survived, every injection channel degraded, every unchecked prose rule drifted**. So: the `UserPromptSubmit` retrieval hook is deleted (it was firing on the words `no` and `a`, ~3.2k tokens a fire, ~41k a session), `triggers:` became a documented grep with its 4–8 cap retired, and two linter bugs that made the script **73% false-positive on a correct project** are fixed — invariant 1 counted **bytes** where the rule says characters (64 false FAILs on a corpus with zero real violations; fatal for any non-English project, since `mawk` is byte-oriented in every locale), invariant 3 required a `headline:` key `evidence.md` never documented (61 false FAILs; `headline:` is now out of the evidence template, and the headline lives in the `# ` title and the INDEX row only). Three invariants added: **19, downward reachability** — evidence cited by no claim, method or deliverable, which is the one direction every existing check was structurally blind to and which found **26% of the pilot corpus stranded with zero dangling references** — **20, the `sources/INDEX.md` cap + one-row-per-doc contract** the evidence index has held at 285 rows with zero violations, and **21, a researcher-authored path into a directory v2 retired** (`decisions/`, `learnings/`, `insights/`, `data_sources/` — 559 live references on the pilot, because a migration is not done when it runs; later merges reintroduce what the repath removed).

**⚠ The constitution changed three times in v3.1, all before the code.** Principle 1: **a hook may enforce, a hook may not inject** — a constitutional bar, not a tunable threshold. Principle 4: **no gitignored file may feed session context** (the pilot's status doc froze 41 days *invisibly* because it was gitignored). New **principle 11: derive state, don't store it** — stored state is a cache with no invalidation, and a research repo has no moment that would invalidate it. There are now **eleven** principles.

**⚠ `lint-research.sh` is still deliberately wired to nothing**, and that was an explicit call, not an oversight. The assessment proposed wiring it; the decision was to fix its accuracy first and wire nothing, because wiring an inaccurate linter is what poisoned it. It is now accurate *and* still unrun by default — `TODO.md` carries that re-opened.

**v3 shipped 2026-09-09 — `package.json` is `0.3.0`.** `plan-r2p-v3` archived the same day: `archive/plan-r2p-v3.md`.

**What v3 is.** v2 established the `deliverable → claim → evidence → artifact → script → source` citation chain and checked almost none of it. v3 checks it, and **adds no migration** — no directory moves, no frontmatter rewrites, `r2p init --upgrade` plus one lint run is the whole adoption. `lint-research.sh` went from 7 checks to **18** and from **11.0s to 2.3s**; `.next-id` acquired the first tool that reads it (`r2p evidence new <slug>`); `/cite-check` walks the half of link 1 no grep can see; `/pipeline-check` re-runs an evidence doc's producing script and diffs against `## Measured`; the second installer has an integration test (`npm test`, 21 assertions). Change table and the four traps: **`docs/v2-to-v3.md`**. Design rationale, including why `save_fig(findings={...})` and a whole-pipeline harness were both rejected: **`docs/citation-chain-mechanism.md`**.

**⚠ The constitution changed twice in v3, both times *before* the code.** Principle 7 now grades additions on a **side-effect axis** (read-only / derived files / source files) as well as token cost, because `/pipeline-check` is the first r2p tier that writes anything — a proposal wanting to write *source* files does not inherit that amendment. And there is now a **tenth principle, "silence reads as a pass"**: a check that finds nothing must say so and name what it examined. It does not contradict principle 1 — ambient mechanisms stay quiet, invoked ones account for everything they examined.

**⚠ Verify before you trust a number here.** Four verifications, all green at v3.1:

python3 templates/migration/03_linkcheck.py --baseline HEAD   # 0 new breaks

**⚠ Run a new lint invariant against a fresh `r2p init`, not just against a mature repo. This caught a live defect again in v3.1** — a new `docs/` pointer in `methods.md` whose "framework repo" marker had **wrapped onto the next line**, so the marker sat on line 135 and the pointer on 134. It resolved perfectly in this repo and dangled in every installed project; only the throwaway install could see it. The marker must be on the *same physical line* as the pointer. Eleven v3 invariants shipped before anyone did, and three of them failed a scaffold containing no research at all — two because the *check* was wrong (a `~/`-prefixed global path is not project-relative; a prose-qualified `docs/` pointer is deliberate), one because the shipped `claims.md` seed carried a placeholder claim. See `docs/field-notes/a-linter-must-be-run-against-a-fresh-install.md`. The rule is now in `docs/extending.md` step 2a: mature project, this repo, throwaway `init` — and the third is the only one whose correct answer is known in advance.

**⚠ The pilot repo is `~/research/cordoba`, and it is a *mixed* v1/v2 install.** Good donor for lint work, bad model of a clean v2 project: it still has `check-evidence.sh` wired and firing (v2 deleted it a year ago; `--upgrade` warns by name but never rewrites a project's `settings.json`) and `.claude/conventions/data-access.md` on disk. Its lint verdict is FAIL with 5 warnings, and that is real defects rather than a regression. **Re-measure before diffing** — a baseline against a live engagement decays in weeks.
